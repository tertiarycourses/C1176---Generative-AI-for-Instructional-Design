## Lab Activities

The 10 labs form one connected practical journey. Complete them in order so each verified output can support the activities that follow.

| # | Activity | Outcome |
|---:|----------|---------|
| **1** | [Set Up Your AI Instructional-Design Toolkit](labs/lab-01-set-up-your-ai-instructional-design-toolkit.md) | Sign in to ChatGPT, Claude, Gemini and an AI image tool, run your first instructional-design prompts, and learn the generate–review–refine loop that every later lab uses. |
| **2** | [Write Effective Prompts for Instructional Design](labs/lab-02-write-effective-prompts-for-instructional-design.md) | Turn a vague ask into a strong, structured prompt (role, context, task, format, constraints) for instructional-design tasks, and save a reusable prompt library for the work you repeat for every course. |
| **3** | [Analyse Learning Needs, Audience and Objectives with AI](labs/lab-03-analyse-learning-needs-audience-and-objectives-with-ai.md) | Use AI to analyse the learning need, profile the target learners as personas, and write clear, measurable learning objectives — the foundation every later artifact must align to. |
| **4** | [Structure the Course Curriculum with AI](labs/lab-04-structure-the-course-curriculum-with-ai.md) | Turn the objectives into a curriculum map — the course's modules, the objectives each module covers, and a logical sequence — so the course has a clear structure before any content is written. |
| **5** | [Build the Lesson Plans and Learning Sequence with AI](labs/lab-05-build-the-lesson-plans-and-learning-sequence-with-ai.md) | Turn the curriculum map into detailed, timed lesson plans — each with its objective, a warm-up, content, an activity and a check — sequenced into a coherent flow ready to develop. |
| **6** | [Generate Learning Content, Activities and Scenarios with AI](labs/lab-06-generate-learning-content-activities-and-scenarios-with-ai.md) | Turn the lesson plans into concrete learning content, active learning activities and a realistic scenario — chunked, written in plain language, and pitched at the learners' level. |
| **7** | [Create Quizzes, Assessments and Rubrics with AI](labs/lab-07-create-quizzes-assessments-and-rubrics-with-ai.md) | Create assessment that measures the objectives — quiz items with answer guides, a scenario-based performance task, and a rubric — all aligned to the learning objectives and checked for quality and fairness. |
| **8** | [Produce Scripts, Visuals and Job Aids with AI](labs/lab-08-produce-scripts-visuals-and-job-aids-with-ai.md) | Produce the learner-facing media — a narration script and storyboard for the e-learning module, on-brand visuals, and take-away job aids — that make the course usable and support performance on the job. |
| **9** | [Align to Outcomes and Quality-Check the AI Output](labs/lab-09-align-to-outcomes-and-quality-check-the-ai-output.md) | Run a full alignment and quality pass — map every artifact to an objective, find gaps and orphans, and check all AI-generated material for accuracy, bias, reading level and instructional soundness before it reaches learners. |
| **10** | [Assemble, Review and Finalise the Course Package](labs/lab-10-assemble-review-and-finalise-the-course-package.md) | Assemble every artifact into one consistent facilitator and learner package, run a final review, and finalise the Meridian Service Excellence course kit ready to deliver — end to end. |

## About

This repository contains the complete lab and courseware package for **Generative AI for Instructional Design** (**C1176**) by Tertiary Courses / Tertiary Infotech. The practical activities build progressively from **Set Up Your AI Instructional-Design Toolkit** to **Assemble, Review and Finalise the Course Package**, with explicit checks that help learners verify each result before moving on.

### What you'll learn

- Complete **10 connected hands-on activities** and carry their outputs through one coherent learning journey.
- Practise with **ChatGPT · Claude · Google Gemini · Microsoft Copilot · Adobe Firefly · Canva · Microsoft Word** and the supporting resources supplied in the repository.
- Begin with **Set Up Your AI Instructional-Design Toolkit** and finish with **Assemble, Review and Finalise the Course Package**.
- Apply safe data handling, evidence checks and named human review before using AI-generated or automated outputs.

## Getting Started

### Prerequisites

- The accounts and software required for **ChatGPT · Claude · Google Gemini · Microsoft Copilot · Adobe Firefly · Canva · Microsoft Word**. Follow the setup and access notes in each lab.
- Review [`labs/tools.md`](labs/tools.md) before class for environment, account and safe-use requirements.
- A modern web browser and Git for cloning the materials.
- Synthetic or authorised data only. Do not place secrets, personal data or confidential material into an unapproved service.
- A named human reviewer for facts, calculations, decisions and any externally released output.

### 1. Clone the repository

```bash
git clone https://github.com/tertiarycourses/C1176---Generative-AI-for-Instructional-Design.git
cd C1176---Generative-AI-for-Instructional-Design
```

### 2. Open the lab index

Start with [labs/README.md](labs/README.md), then complete Labs 1–10 in order. Each lab provides the activity context, practical steps and a way to verify the result.

### 3. Keep your connected outputs

Store each lab output in the suggested working folder and retain the evidence or review notes requested by the lab. Later activities depend on these approved outputs.
